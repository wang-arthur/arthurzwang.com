Footnote → Parenthetical Converter

Upload a .docx file with Word footnotes or endnotes. This tool converts them into inline double-parenthetical citations (((like this))) and produces WordPress-ready HTML you can paste into the block editor's HTML view. Nothing is uploaded — the file is processed entirely in your browser.

About

Ports the notesToParens.py conversion pipeline from the post45-utils repo to run client-side. Uses mammoth.js for DOCX → HTML, then consolidates split formatting tags, fixes whitespace inside <em>/<strong>/etc., and replaces footnote/endnote references with the note text wrapped in double parens.
