Upload a .docx file with footnotes or endnotes. This tool converts them into inline double-parenthetical citations (((like this))) and produces WordPress-ready HTML you can paste into a Post. Nothing is uploaded — the file is processed entirely in your browser.

Scope: the tool primarily handles footnote/endnote conversion. It also:

  • removes embedded images, which should be uploaded separately rather than pasted into the WordPress post. See the Extracted Images section below to download images from the document, or use higher-resolution files from the author if available.
  • converts left-indented paragraphs to <blockquote>.

Everything else — headings, lists, character formatting, alignment, unusual layouts — passes through with minimal cleanup, so please spot-check the output before sharing proofs with the author. The underlying .docx → HTML conversion is done by mammoth.js.
